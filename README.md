# capstone-swiatek-katie
Final Project For UF CJC Capstone Course

    This project is created as the final capstone project for the Masters in Web Design and Online Communication program at the University of Florida. 

    The site will serve as a resource to assist with the creation of color palettes which the user can then utilize for any creative projects. By incorporating the Colormind API (colormind.io) to assist with random color generation, the user can create a wide variety of color options.

    To utilize the site, choose a starting color from the home page. This will populate a selection of three color schemes utilizing the selected base color in various shades. To generate new palette options, click the "Show Me More" button under each line. This will generate new color options for each color set. To view more colors, return to the home page and select a new starting color.
